# Visual specification

Implemented as a 1600 × 900 landscape overview with Chinese Arial/Noto Sans CJK-compatible labels. Solid black arrows denote routine energy flow; the coral dashed arrow denotes contingency supply; paired ochre arrows denote charge/discharge.

## Global style
- Canvas/aspect: landscape, 1600–2200 × 850–1200 px
- Font: Arial/Helvetica (Noto Sans CJK for Chinese)
- Grid/margins: 8 px grid; 16–28 px outer margin
- Corner radius / stroke: 10–16 px / 1.5–2 px
- Arrow grammar: solid filled arrowhead for data; gray dashed for skip/feedback
